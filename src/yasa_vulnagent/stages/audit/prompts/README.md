# Audit prompts

Prompt files support the model-backed audit nodes. Implemented:
`plan/prompt.md`, `trace/prompt.md`, `trace/triage.md`, the
`trace/specialists/*.md` lens prompts, `recon/prompt.md`, and
`verify/prompt.md` / `verify/review.md`.

`gate` and `finalize` are deterministic and intentionally have no prompt.
